# 笔记本引用使用单元格坐标

`.ipynb` 的磁盘行号是 JSON，不是编辑器里看到的源码行。代码引用和诊断引用都写成 `{路径}:cell{N}:{L}`：N 是全部单元格（含 markdown）的 1-based 序号，L 是该单元格内的 1-based 行号。诊断引用的 L 用错误的起始行，不用光标行。序号是复制当时的文档顺序。

## Considered Options

- JSON 行号：和屏幕上的行对不上。
- 只数代码单元格：markdown 单元格会把序号错开。
- 单元格 id：插入单元格后仍稳定，但粘贴出去无法阅读。

## Consequences

插入或删除单元格后，已经复制出去的引用不会更新。非 `.ipynb` 不用这套坐标。
