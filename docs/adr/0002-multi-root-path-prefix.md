# 多根工作区才加文件夹名前缀

单根工作区的代码引用和诊断引用不加重根文件夹名，例如 `memory/03_longterm_memory.py:17`。多根工作区时，两个根里可以有相同的相对路径，所以在路径前加上该文件所属工作区文件夹的配置名称，例如 `backend/src/app.py:17`。两个根同名时不加额外后缀。

## Considered Options

- 始终加文件夹名：单根引用会多一段用不到的前缀。
- 始终不加：多根时 `src/app.py:17` 无法区分来自哪个根。
- 同名根再加路径后缀：引用变长，而且工作区文件里本来就可以改文件夹名。

## Consequences

已经复制出去的多根引用带有复制当时的文件夹名。之后在工作区文件里重命名文件夹，旧引用不会更新。
